# XSSPLOIT Payload Library

Curated, context-based payload sets. **Use only on targets you are authorized to test.**

## Layout

- `context-based/*.txt` — one payload per line, `#` = comment. Grouped by injection
  context so the engine picks contextually-appropriate payloads first.
- `blind-xss/*.txt` — callback payloads. `{CALLBACK}` and `{TOKEN}` placeholders are
  substituted by `CallbackPayloadGenerator` at scan time.
- `payload-index.json` — generated by `pnpm payloads:collect` (see scripts/collector).

## Conventions

- Prefer `alert(1)` / `alert(document.domain)` as proof primitives — non-destructive.
- No browser exploits, no session theft payloads beyond cookie *presence* demonstration.
- Keep lines copy-pasteable raw; encoding variants belong in `waf-bypass.txt`.
